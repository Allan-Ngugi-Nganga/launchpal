How it works

No account needed to scan your first site.

Install the extension

Add LaunchPal to Chrome. It asks for access to the current tab only when you click the icon.

Open the site you built and click the icon

The scan runs locally. A score, a severity list, and one fix prompt per issue.

Paste the prompt into your editor

Each prompt names the file, the risk and the steps, in the format Cursor, Claude Code and Lovable understand.

Verify ownership for a deeper scan

Add one meta tag, and Pro checks for readable .env files, open databases and API routes that answer without a login.

Questions

Does it work on any site?

Yes for free scans, on the page you have open. Deeper scans only run on origins you verify by publishing a token, which is what keeps them from being used against someone else's site.

Do you see my API keys?

No. Detection happens locally and the report masks the value, so even you only see something like sk_live_...0123. Nothing is uploaded.

What does a deeper scan send?

Read-only GET and HEAD requests to your own site, at most 40 per scan, 350 ms apart, with a stop button. No writes, no POSTs, no credentials.

Which tools does it cover?

Anything that runs in a browser. The fix prompts are written for Cursor, Claude Code and Lovable, and read fine in any assistant.

Can I move my licence to another browser?

Yes. Tap Deactivate in Settings, then activate on the other browser. A key allows 2 active browsers.
